# Gestión de versiones – Unidad 2

Para evidenciar el criterio de Git, usa un repositorio propio y realiza commits durante el desarrollo. Los mensajes sugeridos son:

1. `feat: crea estructura inicial del hospital`
2. `feat: agrega componentes institucionales`
3. `feat: implementa servicios e interfaces`
4. `feat: implementa formulario de citas con Signals`
5. `style: mejora responsive con Bootstrap y alertas`
6. `fix: corrige validaciones y almacenamiento de citas`

Comandos básicos:

```bash
git init
git add .
git commit -m "feat: crea estructura inicial del hospital"
git branch -M main
git remote add origin TU_URL_DEL_REPOSITORIO
git push -u origin main
```
