# Hospital Dr. Sano – Unidad 2

Aplicación web institucional desarrollada con **Angular**, **Bootstrap** y **Signals**, según los requisitos de la Unidad 2 de Desarrollo de Aplicaciones Web.

## Requisitos implementados

- Servicios del hospital.
- Médicos y especialidades.
- Reseñas de pacientes.
- Promociones vigentes.
- Diseño responsive con Bootstrap.
- Componentes independientes de Angular.
- Servicios e interfaces para separar responsabilidades.
- Formulario de citas gestionado con Signals.
- Almacenamiento en `localStorage` y listado de citas registradas.
- Alertas Bootstrap para éxito, validación y eliminación.
- Estructura preparada para control de versiones con Git.

## Ejecutar

```bash
npm install
npm start
```

Luego abrir `http://localhost:4200/`.
